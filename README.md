# Smart Inventory and Billing Management System

A JavaFX-based desktop application designed to simplify inventory management, billing operations, stock tracking, and sales monitoring.

## Project Overview

The Smart Inventory and Billing Management System helps manage products, maintain stock records, generate bills, monitor expiry dates, and track sales through a user-friendly dashboard.

## Features

### 1. Dashboard
- View inventory statistics.
- Monitor low-stock products.
- Track expired products.
- View total inventory value.

### 2. Inventory Management
- Add new products.
- Search products by ID or name.
- Update product details.
- Delete products.
- Add or remove stock.
- Store product information using file handling.

### 3. Billing Management
- Add products to the billing cart.
- Manage cart quantities.
- Calculate bill totals.
- Generate billing information.

### 4. Expiry Management
- Monitor product expiry dates.
- Identify expired and soon-to-expire products.
- Suggest discounts based on expiry dates.
- Record removed and returned stock.

### 5. Sales Management
- Maintain sales records.
- View sales reports.
- Track total revenue.
- View daily sales totals.

### 6. Analytics and Stock Management
- View sales analytics.
- Monitor expiry-related information.
- Manage removed and returned stock records.

## Technologies Used

- Java
- JavaFX
- JDK 21
- File Handling
- Object-Oriented Programming (OOP)

## Project Structure

- `Main.java` – Main JavaFX application and user interface.
- `Product.java` – Product information and expiry status.
- `InventoryManager.java` – Inventory operations and file storage.
- `CartItem.java` – Individual billing cart items.
- `CartManager.java` – Shopping cart management.
- `BillingManager.java` – Billing operations.
- `SalesManager.java` – Sales records and reports.
- `ExpiryManager.java` – Expiry alerts and stock history.
